# 에이전트 역할 분담

## data-logic
- 담당: 채점 로직, 산업 카테고리, 엑셀 파싱, 전시 데이터
- 담당 파일: `src/app/lib/scoring.ts`, `data.ts`, `types.ts`
- 추가 필독: `guide/scoring-policy.md`

## ui-dev
- 담당: 화면 컴포넌트 수정 (레이아웃, 버튼, 모달, 리스트, 필터 등)
- 담당 파일: `src/app/components/*.tsx`, `src/app/App.tsx`
- 추가 필독: 없음

## deploy
- 담당: 빌드 및 GitHub Pages 배포
- 담당 파일: `.github/workflows/deploy.yml`
- 추가 필독: `guide/deploy.md`

## general-purpose
- 담당: 파일 시스템 작업, GitHub CLI, 복합 작업
- 추가 필독: 작업 내용에 따라 판단
