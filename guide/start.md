# 세션 시작 가이드

## 에이전트 지시

1. **`guide/handover.md` 읽기** — 현재 상태 및 최근 작업 파악
2. 사용자 요청 내용 파악
3. 요청에 맞는 파일 참고 후 작업 수행
4. **커밋 전 `guide/handover.md` 업데이트** — 현재 상태 갱신 + 로그 1~2줄 추가

---

## 가이드 파일 참고 기준

| 파일 | 언제 읽나 | 내용 |
|------|----------|------|
| `handover.md` | **매 세션 필독** | 현재 상태 + 커밋 로그 |
| `deploy.md` | 빌드·배포 작업 시 | 배포 절차, 커밋 체크리스트 |
| `agents.md` | 역할 분담 확인 필요 시 | 에이전트별 담당 파일 |
| `scoring-policy.md` | 채점 로직 수정 시 | 가중치 설계 원칙 |
| `supabase-images.md` | 이미지 관련 작업 시 | Storage 업로드 방법 |
