# 새 세션 시작 가이드

## 새 세션 첫 메시지 (복붙용)

### 일반 작업
```
guide/handover.md 읽고 현재 상태 파악한 뒤, 아래 작업 진행해줘:

[작업 내용]
```

### 배포 포함 작업
```
guide/handover.md 와 guide/deploy.md 읽고 현재 상태 파악한 뒤, 아래 작업 진행해줘:

[작업 내용]
```

---

## 가이드 파일 목록

| 파일 | 용도 |
|------|------|
| `handover.md` | 최근 작업 상태, 완료·미완료 항목 |
| `deploy.md` | 배포 경로, 커밋 체크리스트, 파일 구조 |
| `agents.md` | 에이전트 역할 분담 |
| `scoring-policy.md` | 채점 가중치 설계 원칙 |
| `supabase-images.md` | Supabase 이미지 업로드 방법 |

> CLAUDE.md(프로젝트 개요·경로·기술스택)는 매 세션 자동 로드되므로 별도로 읽지 않아도 됨
