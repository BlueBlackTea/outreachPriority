# Guide 폴더 안내

새 세션 시작 시 아래 순서로 읽을 것:
1. `CLAUDE.md` — 프로젝트 개요 및 파일 구조
2. `handover.md` — 마지막 세션 인수인계 내용
3. `agents.md` — 에이전트 역할 분담
4. `scoring-policy.md` — 채점 가중치 설계 (필요 시)

## 인수인계 작성 규칙
- 매 세션 종료 후 `handover.md` 업데이트
- 최근 3세션은 상세 기록, 그 이전은 1줄 요약으로 압축
- 미완료 항목은 "⚠️ 미완료" 표시
- 토큰 절약: 완료된 세션은 "Session N: [요약 1줄]" 형태로만 유지
